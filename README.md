# Deanna Miranda — Landscape & Seascape Portfolio

A responsive, single-page photography portfolio designed for GitHub Pages.

## Publish it on GitHub Pages
1. Create a new GitHub repository (for example, `landscape-portfolio`).
2. Upload `index.html` to the repository's main/root folder.
3. Create a folder named `images` and upload your photographs using the filenames listed below.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
6. GitHub will provide your published portfolio URL.

## Add your photographs
Create an `images` folder beside `index.html` and add:
- `hero-coast.jpg` — wide hero image (ideally landscape orientation)
- `coastal-sunrise.jpg`
- `under-the-boardwalk.jpg`
- `moody-shoreline.jpg`
- `open-water.jpg`
- `coastal-detail.jpg`
- `after-the-rain.jpg`

You can rename your files, but if you do, update the matching `src` paths in `index.html`.

## Before publishing
- Replace `your-email@example.com` in the contact button with your preferred public email.
- Update the About text if you'd like a different artist statement.
- Use web-sized copies of your photos (roughly 1600–2200px on the long edge, compressed JPG/WebP) so the page loads quickly.
